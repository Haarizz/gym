Glass tab bar — before / after

The two bugs come from the same root cause: the tab items were sized for icon+label, then the label was removed without resizing the box, and the active state reused a plain white fill that has nothing to contrast against on a light/glass background.

Before — current behaviour

Fixed-height item with leftover label padding, white active fill

Notice the extra empty space below each icon, and the active "Home" tab barely readable against the frosted white bar.

After — fixed

Square item, centered icon, colour-tinted active state

Same 48×48 box for every item regardless of state. Active item gets a low-opacity wash of the role's primary colour, a thin ring in the same hue, and the icon itself renders solid in that colour. Inactive icons drop to a muted slate so the active one reads clearly at a glance — mirrors the reference image's dark-glass bar, adapted for a light/glass context.

React Native translation

primaryColor here is the per-role resolvedColors[0] already computed in RoleTabsLayout.tsx — same value used for the header tint.

const tabBar = { flexDirection: 'row', justifyContent: 'space-around', alignItems: 'center', padding: 10, gap: 4, backgroundColor: 'rgba(255,255,255,0.35)', // was 0.68 (Glass.fillStrong) borderWidth: 1, borderColor: 'rgba(255,255,255,0.55)', borderRadius: 26, }; const tabItem = { width: 48, // fixed box — no residual label padding height: 48, alignItems: 'center', justifyContent: 'center', borderRadius: 16, }; const tabItemActive = (primaryColor) => ({ backgroundColor: `${primaryColor}29`, // ~16% wash borderWidth: 1, borderColor: `${primaryColor}66`, // ~40% ring }); const iconColor = (isActive, primaryColor) => isActive ? primaryColor : 'rgba(30,42,58,0.45)';
