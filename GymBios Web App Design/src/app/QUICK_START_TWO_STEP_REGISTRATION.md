# Quick Start: Two-Step Member Registration

## 🚀 How to Use the New Registration System

### For Front Desk Staff / Sales Team

#### Creating a Draft Registration (Step 1)

1. **Navigate to Plans & Services Catalog**
   - Main Menu → Community → Plans & Services Catalog
   - Or use the direct link from dashboard

2. **Select a Plan**
   - Browse available membership plans
   - Click "Choose Plan" on the desired plan
   - Click "View Details" to see plan benefits (optional)

3. **Start Registration**
   - In the dialog, select **"I'm a New Member"**
   - Click **"Register as New Member"**

4. **Fill Member Information**
   The form has 3 sections:
   
   **Identity & Registration:**
   - Member ID (optional - auto-generated if left blank)
   - National ID / Emirates ID *
   - Email Address *
   - Mobile Number *

   **Personal Information:**
   - Full Name *
   - Date of Birth *
   - Gender *
   - Address (optional)

   **Health & Emergency Information:**
   - Known Medical Conditions (optional but recommended)
   - Emergency Contact Name *
   - Emergency Contact Number *

   `* = Required fields`

5. **Submit Draft**
   - Click **"Request for On-board"**
   - ✅ Success! Member draft created

---

#### Approving & Finalizing Registration (Step 2)

1. **Open Members Directory**
   - Main Menu → Community → Members
   - Look for the 🔔 badge showing pending count

2. **Find Pending Member**
   - Pending members appear at the top of the list
   - Look for "Pending Approval" badge (amber/yellow)

3. **Open Approval Modal**
   - Click the Actions menu (⋮) on the pending member row
   - Select **"Approve to On-board"**

4. **Review Member Information**
   - All draft details are displayed (read-only)
   - Verify personal and health information

5. **Upload Member Photo**
   - Click the photo upload area
   - Choose from camera or upload file
   - Preview appears instantly

6. **Enter Payment Details**
   
   **Payment Mode:**
   - Select: Cash / Card / Online / Wallet

   **Apply Discount (Optional):**
   - Enter promo code:
     - `WELCOME10` = 10% off
     - `MEMBER20` = 20% off
     - `SPECIAL50` = AED 50 off
   - Click "Apply"

   **Transaction ID:**
   - Optional reference number for tracking

7. **Finalize**
   - Review the final amount summary
   - Click **"Confirm & Add Member"**
   - ✅ Member successfully onboarded!

---

### What Happens After Approval?

✨ **Auto-Generated:**
- Member ID (if not provided)
- Invoice Number: `INV-{timestamp}`
- Receipt Number: `RCP-{timestamp}`
- Membership Start Date: Today
- Membership End Date: Calculated from plan duration

📋 **Member Status:**
- Changed from "Pending Approval" → "Active"
- Appears in regular member directory
- Full access to all member features

🗑️ **Draft Removed:**
- Removed from pending list
- Badge count decrements

---

### Rejecting a Draft

If a draft needs to be rejected:

1. Click Actions (⋮) on pending member
2. Select **"Reject / Delete Draft"**
3. Confirm the action
4. Draft is permanently deleted

⚠️ **Warning:** This action cannot be undone!

## 💡 Tips & Best Practices

### For Better Data Quality
- ✅ Always verify Emirates ID format
- ✅ Double-check email addresses
- ✅ Confirm mobile numbers (test with a call/SMS)
- ✅ Ask about medical conditions for safety
- ✅ Take clear, well-lit photos

### Payment Processing
- 💳 Always get transaction IDs for card/online payments
- 🎁 Check if member has promotional codes
- 📧 Email receipt after approval
- 💰 For split payments, document both parts

### Health & Safety
- ⚕️ Medical conditions are confidential - staff only
- 🚨 Emergency contacts are critical - verify accuracy
- 📱 Update emergency contact if member requests

## 🆘 Troubleshooting

### "Draft not showing up"
- Refresh the page (F5)
- Check if draft was successfully submitted (look for success toast)
- Verify localStorage is not disabled

### "Photo upload not working"
- Check file size (max 5MB recommended)
- Use JPG, PNG, or WEBP formats
- Try camera capture instead

### "Discount code not applying"
- Verify code is typed correctly (case-sensitive)
- Check if code exists: WELCOME10, MEMBER20, SPECIAL50
- Some codes may have expiry dates (future feature)

### "Member still showing as pending after approval"
- Refresh the members list
- Check console for errors
- Verify approval was completed (check success toast)
